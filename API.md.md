SmartMail AI — API Documentation
================================

1\. Overview
------------

**SmartMail AI** is a MERN-based intelligent email assistant integrated with Gmail.

The backend exposes REST APIs for:

*   Authentication
    
*   Gmail integration
    
*   Email synchronization
    
*   Email management
    
*   AI-powered email operations
    
*   RAG-based inbox search
    
*   Drafts and sending
    
*   Notifications
    
*   User preferences
    

The backend also uses:

*   **Socket.IO** for real-time events
    
*   **Redis** for caching and queue infrastructure
    
*   **BullMQ** for background processing
    
*   **MongoDB Atlas** as the primary database
    
*   **Gmail API** for email operations
    
*   **Gemini/OpenAI API** for AI capabilities

3\. API Design Principles
=========================

The API follows these principles:

*   RESTful endpoint design
    
*   JSON request and response bodies
    
*   Authentication using secure HTTP-only cookies
    
*   Authenticated user isolation
    
*   Input validation
    
*   Consistent error responses
    
*   Authorization before accessing user resources
    
*   AI operations never automatically send emails
    
*   Long-running tasks can be processed asynchronously using BullMQ
    
*   Sensitive credentials are never returned to the frontend

51\. API Architecture Summary
=============================

SmartMail AI follows a modular REST API architecture:

The API is designed around four major principles:

1.  **Secure user-level data isolation**
    
2.  **Modular AI services**
    
3.  **Asynchronous processing for expensive operations**
    
4.  **Human control over AI-generated email actions**
    

The backend acts as the central layer connecting Gmail, MongoDB, AI services, Redis/BullMQ, and the React frontend while keeping sensitive credentials and business logic on the server.
